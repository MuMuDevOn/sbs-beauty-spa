# Diagrams (Deliverable 2)

Drop finished diagrams here, named `<type>-<short-description>.png` (or `.pdf`/`.drawio`/`.svg`), e.g. `erd-full-schema.png`, `usecase-booking-flow.png`.

Each diagram is drafted **before** the code it describes is written, not reconstructed after the fact.

| Diagram type | Owner |
|---|---|
| EERD, Class Diagram | Database Designer |
| Context Diagram, CRC Cards, Sequence Diagram, DFD | Backend Developer |
| Use Case Diagram, Activity Diagram | Frontend Developer |
| Wireframes | UX Designer *(see `../wireframes/`)* |
